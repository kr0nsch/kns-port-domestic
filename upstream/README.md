# Снимки оригинала

Деревья `src` оригиналов на коммитах, с которых сделан перенос на Astra.IDE. Их не правят: адаптированный
код — в [`targets/astra/`](../targets/astra/README.md).

| Каталог | Оригинал | Коммит |
|---|---|---|
| `kns-pump-station/src` | флагман КНС-1, ветка `main` | `505ce14` |
| `plc-process-lib/src` | библиотека plc-process-lib, тег `v1.0.0` | `bd9df2a` |

Полные хеши, даты и правила — [`SOURCES.json`](SOURCES.json). Снимок — содержимое коммита (`git archive`)
с заменой плейсхолдеров портфолио, как во всём репозитории.

Зачем снимки в репозитории:

- метрики переноса (`tools/port_metrics.py`) считаются от них — в CI и у любого читателя, без рабочих
  копий оригиналов;
- при обновлении оригинала снимок — общий предок для трёхстороннего слияния (`tools/upstream_delta.py`),
  даже если история оригинала перепишется.

Снимок обновляет только `python tools/upstream_delta.py <id> --apply`; `--verify` сверяет снимки с
записанными коммитами (нужны рабочие копии оригиналов рядом с репозиторием).
