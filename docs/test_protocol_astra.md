# КНС-1 в Astra.IDE. Протокол испытаний по ПМИ флагмана

> Бланк протокола: заполняет инженер, который проводит испытания перенесённого ПО КНС-1 в
> Astra.IDE по программе флагмана
> [06_PMI.md](https://github.com/kr0nsch/kns-pump-station/blob/main/docs/06_PMI.md) — без
> изменений программы. Пустые поля оставлены намеренно. Итог по проверке — «соответствует»,
> «не соответствует» (с номером замечания) или «не проверялось» (с причиной). Если проверку выполнил
> сценарий `tests/scenarios/` флагмана, в «Примечаниях» указывают файл отчёта сценария.
>
> Для сравнения рядом с итогом записывают итог той же проверки в CODESYS — из протокола флагмана
> [07_test_protocol.md](https://github.com/kr0nsch/kns-pump-station/blob/main/docs/07_test_protocol.md).
> Перенос считается подтверждённым, если каждая проверка, которая соответствует в CODESYS,
> соответствует и здесь, а отступления согласованы (раздел 4).

## 4. Отступления от ПМИ на этом стенде

Заполняется до начала испытаний. Ожидаемые отступления перечислены заранее; ненужное вычеркнуть,
новое — дописать. Без согласования отступления проверка считается «не проверялась».

| № | Отступление | Причина | Затронутые проверки | Согласовано (кто, дата) |
|---|---|---|---|---|
| О-1 | Стенд — ВПЛК REGUL (или ПЛК REGUL) вместо CODESYS Control Win V3 | цель переноса | все | |
| О-2 | Адрес OPC UA-сервера и NodeId — из настроек цели Astra.IDE | свой сервер вендора, другое дерево узлов | сценарии | |
| О-3 | Время в ВМ не реального времени: выдержки логики — с допуском, фактические значения — в примечаниях | особенность ВПЛК | все с выдержками | |
| О-4 | Обмен с ПЧ и TT403 по Modbus RTU на ВПЛК не проверяется: отказы связи — инъекциями модели | на ВПЛК нет Modbus RTU | PMI-28, PMI-29 | |
